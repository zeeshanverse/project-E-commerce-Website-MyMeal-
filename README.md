# MyMeal — Food Ordering Web Application

MyMeal is a simple food ordering web application built with Flask, HTML, CSS and JavaScript.

Users can browse the menu, add food items to a cart, manage quantities and place an order through the checkout page.

## Features

- Responsive and modern food ordering interface
- Browse food items by category
- Add items to cart
- Increase or decrease item quantity
- Cart total calculation
- Checkout form
- Multiple payment method options
- Bulk delivery and catering request form
- Session-based cart management
- Mobile-friendly design

## Tech Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Jinja2
- Flask-CORS
